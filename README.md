# 🌾 AgriFrance Contacts B2B

> База данных 100 верифицированных сельскохозяйственных предприятий и фермерских хозяйств Франции с официальными контактами, сайтами и распределением по культурам и регионам.  
> **Собрана строго в соответствии с регламентом GDPR ЕС и требованиями технического задания (без персональных данных).**

🔗 **Интерактивная таблица онлайн (GitHub Pages):**  
👉 **[https://watizzzlove.github.io/france-contacts/](https://watizzzlove.github.io/france-contacts/)**

## 📌 Содержание проекта

* `index.html` — интерактивный веб-интерфейс на GitHub Pages (мгновенный поиск, фильтрация по регионам и культурам, карточки контактов, справочник).
* `france_agricultural_contacts_100.xlsx` — профессионально оформленная Excel-таблица с автофильтрами, кликабельными ссылками и боковым справочником обозначений.
* `france_agricultural_contacts_100.csv` — CSV-файл (UTF-8 с BOM, разделитель `;`) для импорта в Google Sheets в 1 клик.
* `generate_perfect_database.py` — автономный Python-скрипт парсинга, валидации и обогащения базы из официальных реестров.

## 🏛️ Источник информации

База собрана на основе официального государственного реестра открытых данных Франции:
* **Портал:** [data.gouv.fr (Plateforme ouverte des données publiques françaises)](https://data.gouv.fr)
* **Ведомство:** *Ministère de l'Agriculture et de la Souveraineté alimentaire* (Министерство сельского хозяйства и продовольственного суверенитета Франции)
* **Реестр:** [Annuaire des exploitations agricoles certifiées Haute Valeur Environnementale (HVE)](https://data.gouv.fr/fr/datasets/annuaire-des-exploitations-certifiees-haute-valeur-environnementale/)

### Что такое сертификация HVE?
**HVE (Haute Valeur Environnementale)** — высший (3-й) уровень государственной сертификации сельского хозяйства Франции. Хозяйства с этим сертификатом — это реальный, платежеспособный агробизнес, инвестирующий в модернизацию, закупку сельхозтехники, биологических препаратов, точного земледелия и агроконсалтинга.

## 🛡️ Стандарты сбора и защита персональных данных (GDPR)

* **Строго без персональных данных:** личные сотовые телефоны, ФИО работников и владельцев, а также персональные почтовые ящики исключены из базы.
* **Только официальные корпоративные каналы:** включены только общие алиасы приёмных (`contact@`, `info@`, `accueil@`, `secretariat@`) и стационарные городские телефоны штаб-квартир.
* Если общий корпоративный адрес не опубликован публично, ячейка оставлена пустой, но предоставлена **прямая ссылка на страницу «Контакты» / форму обратной связи** на официальном сайте.

Для запуска или масштабирования базы (на 500, 1000+ организаций):

```bash
# Установка зависимостей
pip install requests beautifulsoup4 pandas openpyxl

# Запуск сбора и генерации файлов
python generate_perfect_database.py
```
